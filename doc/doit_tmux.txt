INTRODUCTION                                               *doit-tmux-intro*

The DoIt tmux integration provides full todo management from within tmux,
sharing the same data as the Neovim plugin. This allows you to manage your
todos without opening Neovim while keeping both interfaces in sync.

Key features:
- Full CRUD operations (create, read, update, delete)
- Interactive fzf-based manager
- Multiple list support with switching
- Per-tmux-session active lists (see |doit-tmux-session-links|)
- Undo support for accidental deletes
- Status bar integration
- Shared storage with Neovim (session.json)

This is an optional add-on to the core do-it.nvim plugin. For Neovim
plugin documentation, see |doit.txt| (tmux overview: |doit-tmux|)

==============================================================================
REQUIREMENTS                                        *doit-tmux-requirements*

Required:
- tmux (tested with 3.0+)
- fzf (for interactive features)
- jq (for JSON processing)

Optional:
- TPM (Tmux Plugin Manager) for automatic installation

==============================================================================
INSTALLATION                                        *doit-tmux-installation*

Using TPM (recommended):~

Add to your ~/.tmux.conf: >tmux
    set -g @plugin 'bearded-giant/do-it.nvim'
<
Then press `prefix + I` to install.

Manual Installation:~

Clone the repository and source the plugin: >tmux
    run-shell /path/to/do-it.nvim/tmux/doit.tmux
<

After installation, reload tmux config: >bash
    tmux source ~/.tmux.conf
<

KEYBINDINGS                                          *doit-tmux-keybindings*

All keybindings use a two-key sequence starting with `prefix + d`.

Popup Views~
    prefix + d + t     Quick popup viewer (read-only)
    prefix + d + i     Interactive manager (full CRUD)

Quick Actions~
    prefix + d + x     Toggle current todo done/undone
    prefix + d + n     New todo (standalone popup)
    prefix + d + N     Start next pending todo

List Management~
    prefix + d + l     Switch between lists (links the current session)
    prefix + d + L     List manager (create/rename/delete lists)
    prefix + d + d     Daily list popup (interactive manager pinned to the
                       daily list, without touching this session's link)

Alt+Shift Shortcuts (no prefix)~
    Alt+Shift+T        Quick popup viewer
    Alt+Shift+I        Interactive manager
    Alt+Shift+X        Toggle current todo
    Alt+Shift+N        New todo
    Alt+Shift+L        Switch lists
    Alt+Shift+D        Daily list popup

Disable alt bindings in tmux.conf: >tmux
    set -g @doit-alt-bindings off
<

INTERACTIVE MANAGER                                  *doit-tmux-interactive*

The interactive manager (prefix + d + i) provides full todo management
with fzf. Press `?` within the manager to see all keybindings.

Navigation~
    j/k or arrows      Move up/down in list
    K/J                Reorder todo (move up/down; a parent moves with its
                       whole subtree)

Nested Todos~
    Children created in nvim (`a` on the parent) or through the MCP server
    render indented two spaces per level under their parent, inside the
    parent's section and priority group. A done subtask stays under its open
    parent; a pending child of a completed parent follows it below the
    divider. K/J swap a todo with its nearest sibling, so a subtree moves as
    one. Markdown export (E) writes children as an indented list under their
    parent.

Status Changes~
    Enter              Toggle done/pending
    s                  Start (mark in-progress)
    x                  Stop in-progress
    X                  Revert to pending

Editing~
    n                  New todo
    e                  Edit todo text
    P                  Set priority
    g                  Open list notes modal (create/edit/delete notes)

    In new/edit mode: Enter to save, Esc to cancel

List Notes~
    The list has a "Notes" section between the active and completed todos,
    showing scratch notes saved as part of the list (shared with the nvim UI).
    Press `g` (or select a note row) to open the notes modal, where:
        n                  New note (title prompt, then body in $EDITOR)
        e                  Edit selected note
        d                  Delete selected note
        q                  Back to the todo list

View/Copy~
    p                  View full note (scrollable popup, q to exit)
    y                  Copy text to clipboard

Delete/Undo~
    d                  Delete todo (can undo)
    D                  Delete all completed
    u                  Undo last delete

Tags~
    t                  Filter by inline #tag (picker shows usage counts)
    c                  Clear the active tag filter

    Tags are written inline in the todo text, so they are shared with the
    nvim UI and the MCP server. Matching is exact: filtering on `labels`
    shows `#labels` items and not `#labels-web`. Tag names may contain
    letters, digits, `_`, `-` and `/`.

Lists~
    l                  Switch lists
    L                  List manager (create/rename/delete)
    m                  Move todo to another list

Export~
    E                  Export pending todos to markdown

    Writes the current list's non-completed todos to a markdown file: one
    `##` header per priority (Critical, Urgent, Important, Default), items
    in list order, children indented under their parent, each item's note
    indented under it. The path prompt is
    prefilled with `{@doit-export-dir}/{list}.md` (default dir: the popup's
    working directory).

Other~
    r                  Refresh list
    ?                  Show help
    q                  Quit

STATUS BAR                                              *doit-tmux-status*

Add the current todo to your tmux status bar.

In your tmux.conf: >tmux
    set -g status-right '#($DOIT_TMUX_DIR/status/todo.sh "#{session_name}")'
<

Passing `#{session_name}` makes the status resolve the session's linked list
(|doit-tmux-session-links|); status commands run without a client context, so
the script cannot discover the session on its own. Omit the argument for the
old global behavior.

Or with custom formatting: >tmux
    set -g status-right '#{?#{!=:#($DOIT_TMUX_DIR/status/todo.sh),},#[fg=yellow] #($DOIT_TMUX_DIR/status/todo.sh),}'
<

The status shows the currently in-progress todo text (truncated).

SHARED STORAGE                                          *doit-tmux-storage*

Tmux and Neovim share the same todo data through two mechanisms:

Todo Lists:~
    Location: ~/.local/share/nvim/doit/lists/*.json
    Each list (daily.json, work.json, etc.) contains todos for that list.

Session State:~
    Location: ~/.local/share/nvim/doit/session.json
    Tracks the global active list (`.active_list`) and the per-tmux-session
    links (`.sessions`, a `{"<tmux session>": "<list>"}` map — see
    |doit-tmux-session-links|).

When you switch lists in tmux, Neovim sees the change on next refresh.
When you switch lists in Neovim, tmux picks it up immediately.

JSON Schema:~
>json
    {
      "todos": [
        {
          "id": "1234567890_1234567",
          "text": "Todo text here",
          "done": false,
          "in_progress": true,
          "order_index": 1,
          "created_at": 1234567890,
          "priorities": "urgent"
        }
      ],
      "_metadata": {
        "updated_at": 1234567890,
        "deleted_todos": []
      }
    }
<

SESSION-LINKED LISTS                              *doit-tmux-session-links*

Each tmux session can hold its own active list, so hopping between sessions
no longer stomps a single global pointer. Links live in the `sessions` map of
session.json, keyed by tmux session name, and survive tmux server restarts.

Every surface (tmux scripts, the status bar, the MCP server, and Neovim when
it runs inside tmux) resolves the active list through the same chain:

    1. DOIT_ACTIVE_LIST         explicit environment override
    2. sessions[<tmux session>] the session link
    3. project-list derivation  opt-in, |doit-tmux-configuration|
    4. .active_list             the global pointer
    5. daily

Outside tmux, step 2 is skipped and behavior is identical to older versions.

In the list switcher (prefix + d + l) and list manager (prefix + d + L):

    ENTER              Link the selected list to the current session (also
                       refreshes the global pointer)
    g / ctrl-g         Set the global pointer only, touch no link
    u / ctrl-u         Unlink the current session (falls back to the global
                       chain)

The manager uses the bare keys (g, u); the switcher uses ctrl-g and ctrl-u so
plain letters keep filtering the list as you type.

Rows show which sessions link each list, e.g. `work  [api infra]`. Sessions
that no longer exist in `tmux list-sessions` render dimmed. The daily list is
pinned to the top with its pending count.

Switching lists inside tmux — from the tmux UI, from Neovim, or through the
MCP server — writes BOTH the session link and the global pointer. Non-tmux
switches write the global pointer only.

The daily popup (prefix + d + d, or Alt+Shift+D) opens the interactive
manager pinned to the daily list from any session without changing any link
or pointer.

CONFIGURATION                                      *doit-tmux-configuration*

Tmux Options:~

Change the menu key (default: d): >tmux
    set -g @doit-key "t"
<

Disable alt+shift shortcuts: >tmux
    set -g @doit-alt-bindings off
<

Use $EDITOR for create/edit (default: off, uses inline input): >tmux
    set -g @doit-use-editor true
<
When enabled, create and edit operations open $EDITOR (nvim, vim, etc)
instead of the inline readline input. Useful for multi-line todos.

Note popup dimensions (default: 80x20): >tmux
    set -g @doit-note-popup-w "100"
    set -g @doit-note-popup-h "25"
<
Controls the width and height of the popup opened by `p` (view note)
in the interactive manager.

Interactive manager popup dimensions (default: 80% x 80%): >tmux
    set -g @doit-interactive-popup-w "80%"
    set -g @doit-interactive-popup-h "80%"
<
Controls the size of the fzf interactive manager popup (prefix + d + i,
or Alt+Shift+I). Accepts tmux size syntax: absolute cells ("120") or
terminal-relative percentages ("80%"). Percentages scale with the
terminal, so they keep a consistent feel across laptop and ultrawide
displays.

Markdown export directory (default: the popup's working directory): >tmux
    set -g @doit-export-dir "~/notes/exports"

Per-project lists (default: off): >tmux
    set -g @doit-project-lists "on"
<
    A pane inside a git repository resolves to a list named after the
    repository directory, created the first time it is used. Panes outside a
    repository fall back to the session's active list, and DOIT_ACTIVE_LIST
    still wins over both. The nvim side is `modules.todos.project_lists`, and
    both derive the same name for a given repository.
<
Sets the directory prefilled in the `E` (export to markdown) prompt in the
interactive manager. The nvim UI has the same key; its directory comes from
the `export_markdown_path` module option.

Environment Variables:~

The plugin sets these environment variables automatically:
- DOIT_TMUX_DIR: Path to tmux plugin directory
- DOIT_SCRIPTS_DIR: Path to scripts directory

Manual overrides (never set by the plugin):
- DOIT_ACTIVE_LIST: Forces the active list, winning over session links and
  per-project lists. Older versions seeded this globally on every switch;
  that seeding is gone (it would pin every session to one list), and the
  plugin now unsets any stale global copy when it loads.
